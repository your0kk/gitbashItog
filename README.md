# Сайт-визитка

Страница о Юре Ушакове на HTML и CSS для практики Git и GitHub.

## Запуск

1. Скачайте репозиторий.
2. Откройте `index.html` в браузере.

Установка зависимостей и сборка не требуются.

## Файлы

- `index.html` — информация об авторе, контакты и проекты.
- `style.css` — оформление страницы.

После правок обновите страницу и проверьте текст, таблицу и стили. Оба файла должны оставаться в одной папке.
